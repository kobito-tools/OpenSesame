# OpenSesame!

<img src="src-tauri/icons/128x128@2x.png" width="128" alt="OpenSesame! のアイコン" align="right">

**キーを押している間だけ現れるランチャー**です。macOS / Windows で動きます。

左手で「起動キー」（初期値は 左Control + 左Option / Windows は 左Ctrl + 左Alt）を押している間、キーボードの形をしたパネルが画面に表示されます。そのまま登録したキーを押すと、アプリやフォルダが開いたり、前面のウィンドウが画面の左半分・右半分などに整列したりします。

| Windows | Windows 10 / 11（64bit） |

## ダウンロード

このページ右側の **Releases**（または [Releases ページ](../../releases/latest)）を開き、「Assets」から自分のOSに合ったファイルをダウンロードします。

| OS | ダウンロードするファイル |
|---|---|
| macOS | `OpenSesame!_x.y.z_universal.dmg` |
| Windows | `OpenSesame!_x.y.z_x64-setup.exe` |

`x.y.z` はバージョン番号です。「Source code」は開発者向けなので、通常は不要です。

## インストール（macOS）

### 1. アプリをコピーする

1. ダウンロードした `.dmg` ファイルをダブルクリックします。
2. 開いたウィンドウで、**OpenSesame!** のアイコンを右の **Applications** フォルダへドラッグします。
3. デスクトップ（またはFinderのサイドバー）に出ている「OpenSesame!」ディスクを取り出します。

> **必ず「アプリケーション」フォルダに入れてから起動してください。** ダウンロードフォルダなどから直接起動すると、後で出てくる権限設定が保存されないことがあります。

### 2. はじめて開く

このアプリは Apple の有料の開発者登録（公証）を受けていないため、初回だけ macOS の確認を通す必要があります。

1. Finder で「アプリケーション」フォルダを開き、**OpenSesame!** をダブルクリックします。
2. 「“OpenSesame!”は開いていません」「開発元を確認できません」などの警告が出たら、**完了**（または **キャンセル**）を押して閉じます。
3. **システム設定** → **プライバシーとセキュリティ** を開き、下の方へスクロールします。
4. 「“OpenSesame!”は Mac を保護するためにブロックされました」の横にある **このまま開く** を押します。
5. もう一度確認が出たら **このまま開く** を押し、Mac のパスワード（または Touch ID）で許可します。

2回目以降は普通にダブルクリックで起動できます。

<details>
<summary>「壊れているため開けません」と表示される場合</summary>

ダウンロード時の状態によっては、上の手順の代わりにこのメッセージが出ることがあります。その場合は **ターミナル**（アプリケーション → ユーティリティ）を開き、次の1行を貼り付けて Enter を押してから、もう一度起動してください。

```bash
xattr -dr com.apple.quarantine "/Applications/OpenSesame!.app"
```

</details>

### 3. キー入力を受け取る許可（アクセシビリティ）

起動すると設定画面が開き、**「アクセシビリティの許可が必要です」** という案内が表示されます。これは、ほかのアプリを使っている最中でも起動キーを検知するために必要な許可です。

1. 案内の中の **アクセシビリティ設定を開く** ボタンを押します。
2. 開いた一覧の下にある **＋** を押し、「アプリケーション」から **OpenSesame!** を選んで **開く** を押します。
3. 一覧に追加された **OpenSesame!** の横のスイッチを **オン** にします。

数秒で案内が消え、「キーボード監視を開始しました」と表示されれば完了です。アプリの再起動は不要です。

### 4. ウィンドウ操作の許可（最初に使ったときだけ）

ウィンドウを左半分・右半分などに整える機能を初めて使うと、「“OpenSesame!”が“System Events”を制御しようとしています」という確認が出ます。**許可** を押してください。

## インストール（Windows）

1. ダウンロードした `-setup.exe` ファイルをダブルクリックします。
2. 「Windows によって PC が保護されました」と表示された場合は、**詳細情報** を押してから **実行** を押します。
   （このアプリは有料のコード署名を受けていないため、初回にこの確認が表示されます）
3. インストーラーの案内に従って **次へ** → **インストール** を押します。
4. 完了するとスタートメニューに **OpenSesame!** が追加されます。起動すると設定画面が開きます。

Windows では追加の権限設定は不要です。

## はじめての設定

設定画面の上半分にキーボードの絵、下半分に登録した項目の一覧が表示されます。

### アプリやフォルダを登録する

1. 上半分のキーボードの絵で、割り当てたい **空いているキー** をクリックします。
2. 「ウィンドウサイズ変更」「アプリの起動」「フォルダの選択」から選びます。
3. アプリかフォルダを選ぶと、ファイルを選ぶ画面が出るので、登録したいものを選びます。

右上の **＋ アプリ** / **＋ フォルダ** ボタンからも登録できます（空いているキーが自動で割り当てられます）。

登録した項目は下半分の一覧で次の操作ができます。

- 名前をクリックして **表示名を変更**
- キーの選択欄で **割り当てキーを変更**
- **アイコン** ボタンで好きなPNG画像に変更
- **削除** ボタンで登録を解除

### 起動キーを変える

「起動キー」の欄にマウスカーソルを合わせて **delete**（Windows は **Backspace**）キーを押すと表示が消えます。そのまま、使いたい修飾キー（Control / Option / Command / Shift、Windows は Ctrl / Alt / Win / Shift）を1〜3個同時に押して離すと登録されます。左右のキーは区別されます。Esc で取り消せます。

### 表示の切り替え

画面右上で、表示言語（日本語 / English）とキーボード配列（JIS配列 / 英字配列）を切り替えられます。

## 使い方

1. 起動キーを **押したまま** にすると、キーボードの形のパネルが表示されます。
2. 起動キーを押したまま、登録したキーを押すと、アプリやフォルダが開きます。
3. 起動キーを離すとパネルは消えます。

| 操作 | 内容 |
|---|---|
| 起動キー + 登録したキー | アプリ / フォルダを開く、ウィンドウを整える |
| 起動キー + `.`（ピリオド） | 設定画面を開く |
| メニューバー（Windows はタスクバー右下）のアイコン | 設定画面を開く / 終了 |

設定画面の赤いボタン（Windows は ×）で閉じても、アプリはバックグラウンドで動き続けます。

## パソコン起動時に自動で起動する

**macOS**

1. **システム設定** → **一般** → **ログイン項目**（「ログイン項目と機能拡張」）を開きます。
2. 「ログイン時に開く」の下の **＋** を押し、「アプリケーション」から **OpenSesame!** を選びます。

**Windows**

1. **スタート** を右クリック → **ファイル名を指定して実行** を開き、`shell:startup` と入力して **OK** を押します。
2. 開いたフォルダに、スタートメニューの **OpenSesame!** をドラッグしてショートカットを置きます。

## 終了・アンインストール

### 終了

メニューバー（Windows はタスクバー右下の通知領域）の OpenSesame! のアイコンをクリックし、**OpenSesame! を終了** を選びます。macOS では設定画面を前面にして ⌘Q でも終了できます。

### アンインストール

**macOS**

1. アプリを終了します。
2. 「アプリケーション」フォルダの **OpenSesame!** をゴミ箱に入れます。
3. 設定も消す場合は、Finder で **移動** → **フォルダへ移動** を選び、`~/Library/Application Support/io.github.kobito-tools.opensesame` を開いてフォルダごとゴミ箱に入れます。
4. **システム設定** → **プライバシーとセキュリティ** → **アクセシビリティ** の一覧から OpenSesame! を選び、**－** で削除します。

**Windows**

1. アプリを終了します。
2. **設定** → **アプリ** → **インストールされているアプリ** で **OpenSesame!** を選び、**アンインストール** を押します。
3. 設定も消す場合は、エクスプローラーのアドレス欄に `%LOCALAPPDATA%\io.github.kobito-tools.opensesame` と入力して開き、フォルダごと削除します。

## 困ったときは

**起動キーを押してもパネルが出ない（macOS）**

- アクセシビリティの許可を確認してください。アプリを入れ直した・更新した後は、許可の一覧から OpenSesame! を **－** で削除し、**＋** で追加し直すと直ります。
- 初期設定の 左Control + 左Option は、VoiceOver の操作キーと同じです。VoiceOver を使っている場合は起動キーを変えてください。

**起動キーを押してもパネルが出ない（Windows）**

- 管理者として実行しているアプリが前面にあると、Windows の仕組み上キーを検知できません。別のウィンドウを前面にして試してください。

**ウィンドウの整列が効かない（macOS）**

- **システム設定** → **プライバシーとセキュリティ** → **オートメーション** で、OpenSesame! の「System Events」がオンになっているか確認してください。

**「対象が見つかりません」と表示されて保存できない**

- 登録したアプリやフォルダが移動・削除されているか、外付けドライブが外れています。一覧から該当の項目を削除するか、ドライブを接続し直してください。

**設定画面が見当たらない**

- 起動キー + `.` を押すか、メニューバー / 通知領域のアイコンから **設定を開く** を選んでください。

**設定が初期状態に戻った**

- 設定ファイルが壊れていた場合、OpenSesame! は元のファイルを `config.json.broken-<数字>` という名前で残し、初期設定で起動します。上の「アンインストール」に書いた設定フォルダに保存されています。

## プライバシー

- OpenSesame! は **インターネットに一切接続しません。**
- キー入力は、起動キーと登録キーが押されたかをその場で判定するためだけに使い、**記録も送信もしません。**
- 設定は自分のパソコンの中（上記の設定フォルダ）にだけ保存されます。
